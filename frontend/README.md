# NexServe Frontend FINAL

This frontend is aligned with the supplied NexServe authController.

Customer registration sends:
name, email, phone, password, city, area, latitude, longitude.

Worker registration sends:
name, email, phone, password, city, area, skills, experience, latitude, longitude.

Both logins send email + password.

Backend expected at:
http://localhost:5000/api

Run:
npm install
npm run dev
